# CyberSecurity

A personal learning repository documenting my journey through cybersecurity fundamentals — covering CompTIA certification prep (Network+ and Security+) alongside hands-on Python projects.

## Repository Structure

```
CyberSecurity/
├── CompTIA_N10-009_Networkplus/    # Notes, resources & study material for the Network+ (N10-009) exam
├── CompTIA_SY0-701_Securityplus/   # Notes, resources & study material for the Security+ (SY0-701) exam
└── Projects/                       # Hands-on cybersecurity projects and scripts
```

## About

This repo is where I track my progress learning cybersecurity concepts — from networking fundamentals and security principles to practical, code-based projects. It's meant as both a study log and a portfolio of applied work.

- **CompTIA_N10-009_Networkplus** — Study notes and resources aligned with the CompTIA Network+ (N10-009) certification objectives, covering networking concepts, infrastructure, operations, security, and troubleshooting.
- **CompTIA_SY0-701_Securityplus** — Study notes and resources aligned with the CompTIA Security+ (SY0-701) certification objectives, covering threats, architecture, implementation, operations, and governance.
- **Projects** — Practical, hands-on cybersecurity projects that apply the concepts above in code.

## Tech Stack

- **Python** — used across all projects in this repo


## Goals

- Build a solid foundation in networking and security concepts
- Prepare for CompTIA Network+ and Security+ certifications
- Apply theory through practical, hands-on Python projects
